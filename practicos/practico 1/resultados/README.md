# Resoluciones: Práctico 1 (Introducción y Aprendizaje Conceptual)

En este directorio se encuentran las soluciones detalladas, formalizaciones matemáticas, diagramas y simulaciones en Python para cada ejercicio del **Práctico 1**:

---

## 📑 Índice de Ejercicios

* 📄 [**`ejercicio_01.md`**](./ejercicio_01.md): Ámbito de aplicabilidad de ML (casos útiles vs. no útiles) y formalización $(T, P, E)$ de un sistema de recomendación.
* 📄 [**`ejercicio_02.md`**](./ejercicio_02.md): Problema de Pedro juega al fútbol en la playa, conteo del espacio de hipótesis ($|X|=96$, $|H_{\text{sem}}|=973$), traza paso a paso de Candidate-Elimination y clasificación de instancias de test.
* 📄 [**`ejercicio_03.md`**](./ejercicio_03.md): Espacio de hipótesis con disyunciones de 2 conjunciones ($h_1 \lor h_2$), cálculo combinatorio de tamaño y comportamiento de $VS$.
* 📄 [**`ejercicio_04.md`**](./ejercicio_04.md): Implementación en Python de Find-S, verificación con el teórico y simulación Monte Carlo para el concepto $\langle ?, \text{Media}, ?, ?, ? \rangle$.
* 📄 [**`ejercicio_05.md`**](./ejercicio_05.md): Demostración matemática formal del Teorema de Representación del Espacio de Versiones ($s \le_g h \le_g g \iff h \in VS_{H,D}$).
* 📄 [**`ejercicio_06.md`**](./ejercicio_06.md): Concept learning en el plano discreto con rectángulos ($X = \mathbb{N} \times \mathbb{N}$), cálculo de $S$ y $G$, estrategia de Active Learning y muestra mínima para enseñar un concepto.
* 📄 [**`ejercicio_07.md`**](./ejercicio_07.md): Triángulo rectángulo isósceles ($x + y \le a$), espacio de versiones, selección de puntos óptimos, regiones de certeza y análisis de inconsistencia / contradicción.
* 📄 [**`ejercicio_08.md`**](./ejercicio_08.md): Espacio de hipótesis con disyunciones puras de atributos, análisis de dualidad de reglas de generalización/especificación y trazas de $VS_{H,D}$.
