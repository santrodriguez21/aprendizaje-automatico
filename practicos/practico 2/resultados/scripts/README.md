# Scripts en Python: Práctico 2 (Árboles de Decisión)

Colección de scripts ejecutables para verificar, reproducir cálculos paso a paso y visualizar los árboles de decisión de las resoluciones del **Práctico 2**:

---

## 📋 Lista de Scripts

| Script | Ejercicio Asociado | Descripción |
| :--- | :---: | :--- |
| [**`ejercicio_02_entropia_ganancia.py`**](./ejercicio_02_entropia_ganancia.py) | Ejercicio 2 | Cálculo formal de la Entropía de Shannon base $H(S)$ y Ganancia de Información para los atributos $a_1$ y $a_2$. |
| [**`ejercicio_03_id3_pedro.py`**](./ejercicio_03_id3_pedro.py) | Ejercicio 3 | Inducción del árbol ID3 para el problema de Pedro en la playa, agregado de la instancia #5 y predicción sobre instancias 6 a 9. |
| [**`ejercicio_05_poda_arbol.py`**](./ejercicio_05_poda_arbol.py) | Ejercicio 5 | Construcción del árbol de entrenamiento y simulación del procedimiento de post-poda con conjunto de validación (*Reduced Error Pruning*). |

---

## 🚀 Ejecución de los Scripts

Para ejecutar cualquiera de los scripts desde la raíz del repositorio:

```bash
# Ejercicio 2
python "practicos/practico 2/resultados/scripts/ejercicio_02_entropia_ganancia.py"

# Ejercicio 3
python "practicos/practico 2/resultados/scripts/ejercicio_03_id3_pedro.py"

# Ejercicio 5
python "practicos/practico 2/resultados/scripts/ejercicio_05_poda_arbol.py"
```
