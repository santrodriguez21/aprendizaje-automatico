## Ejercicio 4 (15 puntos)

Un agente se mueve horizontal o verticalmente en una cuadrícula “circular” (toroidal), con $\gamma = 0{,}9$. El agente aplica el algoritmo Q, realizando dos episodios de forma secuencial empezando por la casilla sombreada ($\bullet$). La tabla inicial $Q_0$ tiene solo valores nulos, salvo los indicados.

#### Grillas:

**Tabla inicial $Q_0$:**

| | | |
|:---:|:---:|:---:|
| | $\begin{matrix} 200 \\ 90 \end{matrix}$ | 90 |
| 10 | $\begin{matrix} 100 \\ 200 \end{matrix}$ | |
| 40 | $\begin{matrix} 90 \\ 100 \end{matrix}$ | |

**Episodio 1:**

| | | |
|:---:|:---:|:---:|
| | $\downarrow$ | $\leftarrow$ |
| | $\bullet$ | $\uparrow$ |
| | | $\uparrow$ |

**Episodio 2:**

| | | |
|:---:|:---:|:---:|
| | | |
| $\to$ | $\bullet$ | $\to$ |
| | | $\uparrow$ |

- **a)** Dé las tablas $Q_1$ y $Q_2$ sabiendo que en ambos episodios la única recompensa no nula que recibe el agente es al realizar su última acción, con un valor de $+100$.
- **b)** Suponga que el agente guarda en memoria las acciones y retornos durante un episodio. ¿Cuál sería el resultado de la parte (a) si, al finalizar cada episodio, se actualiza $Q$ en orden inverso al recorrido realizado? 
- **c)** Asumiendo que los únicos retornos no nulos son los de los episodios 1 y 2, dé $V^*$, $Q$ y una posible $\pi^*$.
- **d)** ¿Cambia su respuesta de la parte (c) si la recompensa inmediata de la última acción del episodio 2 fuese de $+50$ en lugar de $+100$?

## Fórmulas

- $\text{Entropía}(S) = -\sum p_i \log_2 p_i$
- $\text{Ganancia}(S, A) = \text{Entropía}(S) - \sum_{v \in \text{Val}(A)} \frac{|S_v|}{|S|} \text{Entropía}(S_v)$
- Intervalo de confianza de 95% para la estimación de $\text{error}_D(h)$ utilizando $\text{error}_S(h)$:
  $$\text{error}_S(h) \pm 1{,}96 \sqrt{\frac{\text{error}_S(h)(1 - \text{error}_S(h))}{n}}$$
