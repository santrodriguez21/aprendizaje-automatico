## Ejercicio 1 (10 puntos)

Considere el siguiente ambiente:

```
+-------+-------+-------+-------+-------+
|   X   |       |       |       |   ●   |
+-------+-------+-------+-------+-------+
    4       3       2       1       0
```

En donde:
- Cada casilla es un estado que se numeran, de derecha a izquierda, del 0 al 4.
- El estado 0, representado por el $\bullet$, es el objetivo.
- La **X** representa la posición inicial de un agente, en el diagrama, el estado 4.
- El espacio de acciones es $\{\to, \leftarrow\}$ y el esquema de recompensa es:
  $$r(s, a) = \begin{cases} 5 & \text{si llega al objetivo} \\ -1 & \text{en caso contrario} \end{cases}$$
- El factor de descuento es cierto valor $\gamma$.

- **a)** Dé los valores de la función $V^*$ en este ambiente.
- **b)** ¿Cuál es el valor de $Q(1, \leftarrow)$ para un agente que siga la política óptima?
- **c)** ¿Un agente que siempre toma la acción con mayor valor de $Q$ asociado durante el aprendizaje converge a la política óptima? Justifique.
