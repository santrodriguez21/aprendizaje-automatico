# Algoritmos de Machine Learning

En este paquete se implementarán desde cero (o de forma modular) los algoritmos que se vayan estudiando en la materia para poder reutilizarlos en los prácticos.

### Organización sugerida:
- Módulos según la familia de algoritmos o temas:
  - `supervisado/`: Modelos de regresión, clasificación (KNN, árboles de decisión, regresión logística, etc.)
  - `no_supervisado/`: Clustering (K-Means, DBSCAN), reducción de dimensionalidad (PCA), etc.
  - `metricas/`: Funciones de evaluación de modelos (precisión, recall, MSE, matriz de confusión, etc.)
  - `utils/`: Funciones auxiliares para preprocesamiento de datos, visualización, etc.
